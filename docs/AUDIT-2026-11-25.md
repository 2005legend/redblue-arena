# Master checklist audit — 25 November 2026

Scope: every item in the master verification checklist, audited against this repo tonight.
Legend: **✅ done and verified** · **⚠️ partially done / different shape** · **❌ not implemented**

How this was verified: read the named files, ran `pytest tests -q` (99 passed), started
`python -m arena.cli serve` with `ARENA_KEEP_TARGET=1`, ran a real sweep match through the server,
and screenshotted `/target` and the Arena page during it. Line references are to this commit.

Two items the checklist lists as required (3.4 LLM-first default with `--demo`, 4.2 two-phase
diagnosis) come from the **newer** plan `docs/superpowers/plans/2026-11-24-llm-first-match.md`, whose
own header says it is "approved, **not implemented yet**". They are not regressions; they are a
deliberately deferred redesign, and the README says so. Everything else is in the shipped path.
